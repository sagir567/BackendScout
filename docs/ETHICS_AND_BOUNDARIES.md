# Ethics And Boundaries

BackendScout should help with honest positioning, not deception.

## Allowed

- Reordering CV sections for relevance.
- Emphasizing real experience that matches the role.
- Rewriting bullets to be clearer and more specific.
- Creating tailored cover notes based on truthful facts.
- Summarizing jobs and identifying gaps.
- Preparing study material for missing skills.

## Not Allowed

- Inventing experience, skills, employers, education, certifications, dates, or outcomes.
- Adding deliberate spelling mistakes to evade AI detection.
- Misrepresenting availability, location, compensation, citizenship, or work authorization.
- Bypassing CAPTCHA, paywalls, logins, rate limits, or anti-abuse controls.
- Submitting applications without explicit approval.

## Design Principle

The user should always be able to explain every submitted CV line in an interview.
