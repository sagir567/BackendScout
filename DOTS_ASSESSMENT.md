# Dots for BackendScout

Assessment based on official documentation reviewed 30-31 October 2026.

## Recommendation

Try Dots as an optional user interface and research coordinator **if it is already
available on the current account**. Do not purchase a more expensive subscription
solely to replace a small background worker. Keep application versions, approvals,
attempts, and proof in BackendScout's deterministic ledger. This is an architectural
recommendation, not a completed integration or proof that the account is eligible.

## What It Offers

Dots has a cloud computer and can continue cloud work while personal devices are
off. It can delegate work to Work/Codex threads and connect supported apps such as
Gmail and GitHub. Local-computer work still needs that computer online with the
ChatGPT app open. Cloud and local browser logins are separate; some websites block
cloud browsers or require additional verification.
[Official computers and apps guide](https://learn.chatgpt.com/docs/dots/computers-and-apps).

The published rollout lists eligible Pro tiers, Business Premium and Enterprise,
with geographic/admin restrictions and gradual availability. Conversation usage
and delegated Work/Codex usage are treated differently; delegated tasks still use
their products' limits. The account's actual access and remaining allowance need
checking before any pilot. Do not assume a regular subscription includes Dots.
[Official access and limits](https://learn.chatgpt.com/docs/dots).

Setup can start in the mobile app, desktop app or desktop browser. Mobile web is
not supported. Built-in safeguards and approval checks still apply; telling a dot
to act autonomously does not remove every interaction.
[Official getting started guide](https://learn.chatgpt.com/docs/dots/getting-started).

## Where It Fits

- Useful pilot: explain today's shortlist, collect missing evidence, review a CV,
  summarize replies, and delegate a bounded development/research task.
- Keep deterministic: exact-file approval, deduplication, delivery audit, retry
  classification, proof storage and source health.
- Do not assume: direct Telegram control, an arbitrary Dots API endpoint, guaranteed
  overnight throughput, persistent employer login, or universal automatic submission.
  The reviewed product pages do not establish those integration contracts.

## Small Pilot

1. Confirm Dots appears in the account before changing any subscription.
2. Use a synthetic profile and two public job descriptions. Ask for a draft-only
   comparison with cited evidence and explicit unknowns.
3. Repeat from the phone with the Mac off. Verify the work is actually cloud-based
   and documents remain reachable. Do not upload the private archive by default.
4. Record time, user interruptions, accuracy and allowance consumed. Separately
   test one authorized app connection only if needed.
5. Adopt it only if it improves this workflow over the planned small web interface.

No Dot, new subscription, plugin connection, or recurring cloud task was created
as part of this assessment.
