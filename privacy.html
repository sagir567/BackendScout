Privacy Policy

BackendScout is operated by Sagi Yosef Azulay for personal job-search use. This public information site does not connect to Gmail, offer a sign-in, or collect applications. The private installation is separate.

Google user data

When the owner connects Gmail, the private installation requests read-only access to find job recommendations and employer replies, and send access to deliver messages the owner approves. Gmail read-only permission is mailbox-wide; BackendScout uses targeted searches to limit which messages it retrieves. It can read sender, subject, timestamp, message identifiers, and message content to identify jobs or classify recruitment outcomes. It does not modify or delete messages through Gmail.

Storage and sharing

The local installation keeps authorization in the operating system credential store by default on macOS. It stores workflow records and processed message identifiers locally. Depending on configuration, it can write relevant status and audit details, including sender, subject and message ID, to the owner’s private Notion tracker, and send job or status summaries, which can include email subjects, to the owner’s private Telegram chat. Recommendation details can be used to create job records. Reviewed application emails and attachments are sent to the employer recipient approved by the owner.

Google user data is used to provide these job-search functions, not sold, used for advertising, or used to train generalized AI models. BackendScout’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and removal

Workflow and audit records remain in the local installation and configured destinations until the owner deletes them. The owner can revoke access in Google Account connections and remove the locally stored credential. Revocation stops API access; previously stored local, Notion, and Telegram records can be removed separately in those services.

Public site and contact

These pages use no application analytics or tracking scripts. GitHub Pages may process visitor information as described in its hosting documentation. For privacy questions, contact the project maintainer via the GitHub profile; do not post private information in public issues.
