ENGINEERING CASE STUDY

BackendScout

A local-first job-search agent with human review built into the workflow.

Built by Sagi Yosef Azulay

Explore the architecture ↓

01 / WORKFLOW

From discovery to a reviewed application

  1. 01

    Discover

    Collect listings, remove duplicates, and distinguish discovery links from official application destinations.

  2. 02

    Prepare

    Score fit transparently and draft a role-specific CV from verified career evidence.

  3. 03

    Review

    Bind approval to the exact CV version, destination, and answers. A changed package requires fresh review.

  4. 04

    Track

    Track receipts and employer replies. An uncertain submission stays locked against automatic retry.

02 / SYSTEM DESIGN

Local state.
Explicit approvals.

I built BackendScout to make my own job search more systematic and to learn how to build agents that can recover from failures without repeating consequential actions.

Python · FastAPI
Private review workspace and shared application services.
SQLite · DBOS
Application state, durable tasks, and recovery.
Playwright · OpenAI
Form inspection for supported routes and evidence-backed CV drafting.
Gmail · Telegram · Notion
Employer replies, private alerts, and a synchronized tracker.

03 / PROJECT STATUS

Built and tested locally

Employer form support varies by route. Automatic submission is limited to routes that pass preflight and exact-package approval; unsupported routes remain manual. Cloud deployment is not presented as an existing capability.
